# Proposed Milestone 8 — Garment Digitization Preprocessing

**Status:** Proposed only; Milestone 8 has not started.

The next bounded milestone should design and validate garment segmentation,
transparent-background assets, front/back normalization, input-quality checks,
primary/secondary colour extraction, pattern extraction, layer-role refinement,
season suggestions, and a normalized try-on-ready 2D garment asset.

It should establish provenance, validation fixtures, failure behavior, rights-safe
storage, and quality metrics before provider integration. It must not perform 3D
generation, body fitting, virtual try-on, multi-garment rendering, or external
provider benchmarking; those remain later work.
