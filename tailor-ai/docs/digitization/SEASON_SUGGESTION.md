# Season and Layer Suggestions

Season is deterministic, advisory, multi-label, and editable. It uses confirmed category—not pixels or inferred fabric warmth. Defaults include short sleeves for spring/summer, shorts for summer, and outerwear or trousers for spring/fall/winter. Stored provenance begins as `system_default` and user review overrides it.

Layer role is product logic: tops → `top`, shorts/trousers/skirts → `bottom`, dresses → `one_piece`, outerwear → `outerwear`, and unknown → `unknown`. Segmentation never redefines category.
