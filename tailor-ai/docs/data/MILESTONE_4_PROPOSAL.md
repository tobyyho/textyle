# Milestone 4 Proposal Gate

> **Approved and superseded by Milestone 4 execution on 2026-08-06.** The user selected the seven-class baseline option while retaining sleeveless in the product taxonomy.

Milestone 4 is not started. Fashionpedia supplies a viable provisional pilot for seven classes but only 24 `sleeveless_top` instances, below the 150-instance hard feasibility threshold.

Before model work, the user must approve one of these future directions: acquire an authorized complementary source/custom Textyle-style sleeveless set while preserving held-out garments; merge/remove the sleeveless class through a new taxonomy decision; or explicitly authorize a seven-class baseline while treating sleeveless as unsupported. The recommended direction is targeted custom/authorized sleeveless data because it preserves the intended API taxonomy.

Only after that data decision may a separately approved Milestone 4 cover official torchvision EfficientNet-B0 weights, front-only Dataset/DataLoader code, deterministic transforms, a bounded memory probe, smoke/pilot training, evaluation, and calibration. No API belongs in that milestone.
