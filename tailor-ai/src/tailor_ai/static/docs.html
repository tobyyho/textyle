Tailor API v1

Tailor baseline v0.1 does not support sleeveless_top.

Endpoints

GET /healthz process liveness

GET /readyz verified model readiness

GET /api/v1/model model metadata

GET /api/v1/categories taxonomy metadata

POST /api/v1/clothing/classify multipart classification; requires X-API-Key

OpenAPI 3.1 schema

Classification fields

Required: front_image. Optional: back_image, source, and client_request_id. The back image is accepted but ignored by model v0.1.
